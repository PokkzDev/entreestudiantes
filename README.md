# Entre Estudiantes

Entre Estudiantes es una plataforma web pensada para estudiantes universitarios, donde pueden conectar, vender productos, ofrecer servicios y encontrar lo que necesitan dentro de una comunidad confiable y segura.

## Características principales

- **Registro y autenticación segura**: Crea tu cuenta con verificación de correo electrónico y gestiona tu perfil.
- **Publicación de productos y servicios**: Publica fácilmente productos (libros, tecnología, ropa, arte, etc.) o servicios (tutorías, diseño, traducción, etc.) con fotos, descripciones, precios y datos de contacto.
- **Búsqueda avanzada**: Filtra publicaciones por tipo (producto o servicio), categoría y palabras clave.
- **Gestión de publicaciones**: Edita, pausa, reactiva o elimina tus publicaciones desde tu panel personal.
- **Contacto directo**: Comunícate con otros estudiantes por WhatsApp, email o teléfono, sin intermediarios.
- **Configuración de cuenta**: Cambia tu contraseña, elimina tu cuenta y administra tu información personal.

## ¿Cómo funciona?

1. **Crea tu cuenta**: Regístrate gratis y completa tu perfil universitario.
2. **Publica productos o servicios**: Añade fotos, descripción, precio y tu forma de contacto preferida.
3. **Conecta con otros estudiantes**: Recibe mensajes directos de interesados y coordina la venta o el servicio.

## Tecnologías utilizadas

- **Next.js** (React) para el frontend y backend (API routes)
- **Prisma ORM** y **MySQL** para la gestión de base de datos
- **NextAuth.js** para autenticación
- **React Icons** para iconografía
- **Resend** para envío de correos electrónicos
